# MEMORI AI

تطبيق أندرويد باسم MEMORI AI بواجهة متعددة اللغات (العربية والإنجليزية والإسبانية والفرنسية والألمانية والإيطالية والبرتغالية والروسية والصينية واليابانية والكورية والهندية والتركية والإندونيسية والأردية). تتبع الواجهة لغة الجهاز تلقائيًا، ويمكن تغيير لغة التطبيق بشكل مستقل من إعدادات التطبيقات على Android 13 فأحدث. اللغات المضمنة: العربية والإنجليزية والإسبانية والفرنسية والألمانية والإيطالية والبرتغالية والروسية والصينية واليابانية والكورية والهندية والتركية والإندونيسية والأردية. لا تتضمن حزمة اللغات اللغة العبرية.

## المتطلبات
- Android Studio حديث
- JDK 17
- Android SDK Platform 35
- Gradle 8.7

## البناء محليًا
1. افتح المستودع في Android Studio.
2. انتظر مزامنة Gradle وتنزيل Android SDK المطلوب.
3. شغّل المهمة `:app:assembleDebug`.
4. ملف APK الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

## البناء التلقائي
كل دفع إلى فرع `main` أو تشغيل يدوي لسير العمل `MEMORI AI Android APK` يبني نسخة Debug APK. بعد نجاح التشغيل، نزّل العنصر `MEMORI-AI-debug-apk` من صفحة Actions.

## الحالة الحالية والحدود
- الواجهة النصية موجودة.
- إدخال الكلام يستخدم لغة الجهاز الحالية عبر خدمة التعرف على الكلام المتاحة على الجهاز، ويتطلب إذن الميكروفون عند الاستخدام.
- قراءة النص تستخدم لغة الجهاز الحالية عبر Android TextToSpeech إذا كانت بيانات الصوت متاحة على الجهاز.
- **المحادثة الذكية الفعلية غير موصولة بعد**: يلزم إعداد مزود نموذج وخادم وسيط آمن. لا تضع مفاتيح API سرية داخل التطبيق أو المستودع.
- لا ينفذ التطبيق إجراءات على الهاتف دون طلب الإذن المناسب من المستخدم. ولا يملك أندرويد واجهة تسمح لأي تطبيق بقراءة كل بيانات الهاتف أو التحكم الكامل فيه دون قيود وصلاحيات خاصة.
