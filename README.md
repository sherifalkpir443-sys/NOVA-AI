# MEMORI AI

تطبيق أندرويد باسم MEMORI AI بواجهة متعددة اللغات. تتبع الواجهة لغة الجهاز تلقائيًا، ويمكن تغيير لغة التطبيق بشكل مستقل من إعدادات التطبيقات على Android 13 فأحدث. اللغات المضمنة: العربية والإنجليزية والإسبانية والفرنسية والألمانية والإيطالية والبرتغالية والروسية والصينية واليابانية والكورية والهندية والتركية والإندونيسية والأردية. لا تتضمن حزمة اللغات اللغة العبرية.

## المتطلبات
- Android Studio حديث
- JDK 17
- Android SDK Platform 35
- Gradle 8.7

## البناء محليًا
1. افتح المستودع في Android Studio.
2. انتظر مزامنة Gradle وتنزيل Android SDK المطلوب.
3. شغّل المهمة `:app:assembleDebug`.
4. ملف APK الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

## البناء التلقائي
كل دفع إلى فرع `main` أو تشغيل يدوي لسير العمل يبني نسخة Debug APK. بعد نجاح التشغيل، نزّل العنصر `MEMORI-AI-debug-apk` من صفحة Actions.

## توصيل محرك الذكاء الاصطناعي
المحادثة الحقيقية تتطلب خادمًا وسيطًا تملكه وتتحكم فيه؛ لا تضع مفاتيح مزود الذكاء الاصطناعي داخل APK أو GitHub. من داخل التطبيق افتح **Settings** وأدخل عنوان الخادم HTTPS. يرسل التطبيق:
- `POST /chat`
- `Content-Type: application/json`
- جسم الطلب: `{"message":"...","language":"en-US"}`
- الاستجابة المتوقعة: `{"reply":"..."}`

يجب على الخادم التحقق من المستخدم، وإدارة مفتاح مزود النموذج سرًا على الخادم، ووضع حدود للطلبات، وعدم تسجيل البيانات الحساسة. التطبيق لا يدّعي وجود ذكاء اصطناعي عند عدم ضبط الخادم، ويعرض رسالة واضحة بدل ردود تجريبية.

## الوظائف وحدود أندرويد
- إدخال الكلام يستخدم خدمة التعرف على الكلام المتاحة على الجهاز، ويتطلب إذن الميكروفون عند الاستخدام.
- قراءة الردود صوتيًا تستخدم Android TextToSpeech إذا كانت بيانات اللغة متاحة على الجهاز.
- عنوان الخادم يُحفظ محليًا في إعدادات التطبيق، ويُقبل HTTPS فقط.
- لا يستطيع تطبيق أندرويد عادي قراءة كل بيانات الهاتف أو التحكم الكامل فيه. كل وظيفة إضافية تحتاج صلاحيات Android المناسبة وموافقة المستخدم، وبعض الوظائف محظورة أو مقيدة بالنظام.
- لم يتم توصيل خادم AI خارجي أو اختبار التوافق مع مزود محدد لعدم وجود عنوان خادم وبيانات اعتماد مقدمة للمشروع.
